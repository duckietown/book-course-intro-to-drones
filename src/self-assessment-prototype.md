```{seo}
:description: Three practice questions demonstrating the book-local Introduction to Robotics with Drones self-assessment prototype.
```

These three questions demonstrate a book-local practice component. Choose one
answer and select **Check answer**. You can retry freely; answers are not saved
or reported. Without JavaScript, use **Answer and explanation** below each question.

```{dt-question}
:id: steady-hover
:correct: b
:feedback-correct: In steady hover, vertical acceleration is zero, so thrust balances weight.
:feedback-incorrect: Think about the vertical force balance when acceleration is zero.

What vertical force balance is required for steady hover?

- (a) Total thrust is zero.
- (b) Upward thrust balances the drone's weight.
- (c) Upward thrust continuously exceeds the drone's weight.
```

```{dt-question}
:id: angular-velocity
:correct: a
:feedback-correct: A gyroscope measures angular velocity about its sensing axes.
:feedback-incorrect: Consider which sensor measures rotation rather than distance or images.

Which sensor measures **angular velocity**?

- (a) A gyroscope.
- (b) A time-of-flight range sensor.
- (c) A camera.
```

```{dt-question}
:correct: c
:feedback-correct: Proportional feedback responds to the current difference between target and measured altitude.
:feedback-incorrect: The error is the difference between the target and the measured value.

What does the proportional term of an altitude controller respond to?

- (a) Only the accumulated past altitude error.
- (b) Only the rate of change of altitude error.
- (c) The current altitude error.
```
